找不到器材？
  1. 看器材的燈：慢慢閃（每 0.5 秒）＝等待連線，正常；恆亮＝已經被別的裝置連走了。
  2. 關掉手機上的小程序，或把手機藍牙關掉；舊的測試網頁分頁也要關掉。
  3. 短按電源鍵會切換「藍牙／有線」模式：閃藍光＝藍牙模式（正確），閃青色＝有線模式，要再短按一次切回藍牙。
  4. 還是找不到，按這裡顯示所有藍牙裝置：，找名稱開頭是 Force 的那一個。
  5. Mac：系統設定 → 隱私權與安全性 → 藍牙，確認 Google Chrome 已開啟。

這個瀏覽器不支援網頁藍牙。請在電腦或安卓手機上用 Chrome 開啟本頁；iPhone／Safari 不支援。

器材校正建議每次測試前用啞鈴檢查一次
  1. 器材上不放任何東西，按「量零點」。
  2. 放上啞鈴（測力台放中央；測力計直接吊掛），靜止後按「量啞鈴」。
  3. 誤差超過 1% 才需要校正。按下後會寫入器材並永久保存（小程序也會使用新的數值）。
  4. 拿掉啞鈴再放回去，看即時數字是否接近啞鈴重量，確認校正成功。

雙機模式（兩塊測力台）要分別連線、各自校正。誤差很大時可先「恢復原廠比例」再重新校正。
